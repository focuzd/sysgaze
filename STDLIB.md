# Standard-library and platform substitutions

Sysgaze is written from scratch in C23. It has no third-party runtime or test
dependencies and contains no copied or vendored library source. Under the event
rules for C, libc, POSIX, the compiler/build tools, and Linux platform APIs are
permitted. Linux UAPI headers describe the kernel ABI; they are not linked or
shipped as a library.

The substitutions below are the places where a conventional implementation
would commonly introduce a package.

1. **CLI framework → `getopt_long` plus explicit validation.** `src/cli.c`
   handles short/long options, typed limits, mutually exclusive modes, the
   `-- COMMAND` boundary, help, versioning, and exit-code contracts without a
   command-line parsing library.

2. **Tracing library → Linux `ptrace` and `waitpid`.** `src/trace.c` drives an
   explicit per-TID stop state machine using `PTRACE_SEIZE`,
   `PTRACE_GET_SYSCALL_INFO`, ptrace events, and `waitpid(..., __WALL)` instead
   of linking libunwind, libproc, or another tracing engine.

3. **Remote-memory helper → `process_vm_readv`.** Tracee strings, buffers,
   argv arrays, socket addresses, and selected structures are copied through a
   bounded Linux system call. Partial reads, races, null pointers, and `EFAULT`
   are handled locally rather than delegated to a process-inspection package.

4. **`libseccomp` → raw classic BPF from Linux UAPI structures.** Sysgaze
   constructs `sock_filter` instructions itself, installs them with
   `PR_SET_NO_NEW_PRIVS` and the `seccomp` syscall, validates
   `AUDIT_ARCH_X86_64`, and switches between `PTRACE_EVENT_SECCOMP`,
   `PTRACE_SYSCALL`, and `PTRACE_CONT`.

5. **JSON library → manual schema-specific serialization.** `src/output.c`
   writes NDJSON trace events and finite JSON summaries directly. Its escaper
   covers control characters, quotes, backslashes, and invalid byte values;
   potentially unsafe 64-bit JSON numbers are emitted as strings.

6. **Dynamic-string package → checked `realloc` buffer.** `src/buffer.c`
   provides overflow-checked growth, formatted appends, byte appends, reset,
   and ownership transfer using only libc allocation and formatting APIs.

7. **Hash-table package → open-addressed TID table.** `src/tracee_table.c`
   implements power-of-two growth, collision handling, tombstones, deletion,
   and state migration for exec without uthash, GLib, or a C collections
   library.

8. **Process enumeration library → `/proc` plus POSIX directory I/O.** Attach
   mode reads `/proc/PID/task` with `opendir`/`readdir`, stabilizes the task
   snapshot, and reads `/proc/TID/status` to distinguish TIDs from thread-group
   IDs without libprocps.

9. **Syscall database package → generated Linux UAPI metadata.** The checked-in
   unified catalog is generated by the repository's shell/AWK tools from
   `asm/unistd_64.h`, `include/linux/syscalls.h`, checked architecture-specific
   arities, and original project decoding/classification metadata. Unknown
   future syscall numbers still render safely as `syscall_N`.

10. **Enum/flag formatting helpers → declarative local tables.**
    `src/decoder.c` decomposes open, mmap, clone, signal, socket, and related
    bitmasks while preserving unknown bits. `strerrorname_np`, `strsignal`, and
    libc formatting supply platform names where available.

11. **Statistics/dataframe package → arrays, `qsort`, and integer math.**
    `src/stats.c` grows per-syscall rows, checks counter overflow, computes
    elapsed and average nanoseconds, and applies a deterministic duration/name/
    number ordering.

12. **Event loop or signal package → `sigaction` and synchronous waits.** The
    tracer uses async-signal-safe handlers only to set a `sig_atomic_t` flag;
    cleanup, signal reinjection, group-stop handling, detach, and reap work stay
    in the main wait loop.

13. **Benchmark framework → `fork`, `execve`, `wait4`, clocks, and rusage.**
    `benchmarks/harness.c` performs warmups, thirty-sample runs, median/min/max
    calculations, CPU accounting, event checks, and ptrace-call telemetry
    without a benchmarking package or `/usr/bin/time`. System strace is an
    optional comparison subject, and AWK formats the compact `make bench-smoke`
    report; neither participates in Sysgaze's own timing implementation.

14. **Unit/integration test framework → small C and POSIX shell harnesses.**
    Assertions, JSON syntax validation, deterministic fixtures, exit-status
    checks, signal tests, attach cleanup, and ptrace parity checks use the C
    compiler, libc/POSIX, the shell, and standard platform utilities such as
    `grep`, `sed`, `mktemp`, and `awk`. `make check` additionally uses compiler-
    supplied AddressSanitizer and UndefinedBehaviorSanitizer instrumentation;
    sanitizer runtimes are linked only into test builds, never the release
    artifact.

15. **JSON test dependency → purpose-built C validator.**
    `tests/ndjson_validator.c` validates the exact JSON grammar needed by the
    trace and summary schemas, including strings, numbers, objects, arrays,
    literals, whitespace, and trailing-data rejection.

16. **Reproducible-build service → compiler prefix maps and platform tools.**
    `make repro-check` fixes `SOURCE_DATE_EPOCH`, removes absolute source paths
    with GCC-compatible prefix maps, performs two clean builds, compares them
    in distinct source directories, compares them with `cmp`, and publishes
    both `sha256sum` values. Dependency proof additionally uses `readelf`,
    `find`, `grep`, `sed`, and `sort`. These are development-time verification
    commands and are not runtime requirements.

## External-code disclosure

No third-party source was copied into this repository. The syscall catalog's
names, numbers, and generic arities are mechanical facts generated from locally
installed Linux kernel headers by the project's own shell/AWK tools. The MIT
license covers the project source; Linux header names and numeric ABI constants
remain facts of the target platform.

System `strace` is optional and used only as an external comparison subject by
`make bench-smoke` when available and by `make bench-compare`. It is not needed
to build, test, or run Sysgaze. Neither strace nor any shell/AWK/proof utility
is linked into or executed by the shipped `build/sysgaze` artifact.
